# Icon sources

These icons are adapted to 48 x 48 tiles with the same dark background as Skill Icons.

- `cursor.svg`: [Cursor](https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/cursor.svg), Simple Icons, CC0-1.0.
- `github-copilot.svg`: [GitHub Copilot](https://cdn.jsdelivr.net/npm/simple-icons@v16/icons/githubcopilot.svg), Simple Icons, CC0-1.0.
- `antigravity.svg`: [Antigravity](https://github.com/lobehub/lobe-icons/blob/master/packages/static-svg/icons/antigravity-color.svg), LobeHub Icons, MIT (notice below).
